# QWERTY Switcher 🚀 v1.0.0

Легковесный, умный и ненавязчивый автоматический переключатель раскладки клавиатуры (RU <-> EN) для Windows в системном трее с поддержкой автозапуска.

---

## 🌟 Возможности

1. **Мгновенная работа в системном трее**:
   - Тихо висит возле часов, не отвлекая и не занимая место в панели задач.
   - **Динамический индикатор языка**: иконка в трее в реальном времени подсвечивает текущий язык активного окна — **`RU`** (рубиново-красный) или **`EN`** (синий), либо **`OFF`** (серый), когда программа на паузе.

2. **Автоматическое исправление опечаток (Auto-switch)**:
   - При наборе слова в неверной раскладке (например, `ghbdtn` вместо `привет`, `vj;tim` вместо `можешь` или `руддщ` вместо `hello`) программа автоматически исправляет слово при нажатии **Пробела** или **Enter** и переключает язык Windows.

3. **Умный откат по Backspace (Undo)**:
   - Если программа ошиблась и переключила слово, которое вам было нужно как есть — просто нажмите **`Backspace`** сразу после автоисправления.
   - Программа мгновенно вернет исходное слово и раскладку назад, а также добавит это слово в сессионный черный список, чтобы больше его не трогать.

4. **Горячая клавиша `Pause / Break`**:
   - **Для выделенного текста**: выделите любой фрагмент или целое предложение в браузере, мессенджере или коде и нажмите `Pause` — текст мгновенно конвертируется в другую раскладку, а язык системы переключится.
   - **Для последнего набранного слова**: нажмите `Pause` без выделения.
   - **Для всей строки (`Shift + Pause`)**: конвертирует всё последнее набранное предложение из буфера.

5. **Смена регистра текста (`Alt + Pause` или `Shift + F3`)**:
   - Циклически меняет регистр выделенного текста:
     `ПРИВЕТ` $\rightarrow$ `привет` $\rightarrow$ `Привет` $\rightarrow$ инверсия регистра.

6. **Быстрое переключение раскладки по двойному `Shift`**:
   - Два быстрых нажатия левого или правого `Shift` переключают раскладку активного окна без необходимости тянуться к `Alt + Shift` или `Win + Space`.

7. **Текстовые сниппеты и автозамена**:
   - `@@` + Пробел $\rightarrow$ вставляет ваш email.
   - `дд` или `dd` + Пробел $\rightarrow$ вставляет сегодняшнюю дату (например, `03.09.2026`).
   - `вв` или `tt` + Пробел $\rightarrow$ вставляет текущее время.

8. **Черный список приложений и игр**:
   - В играх (CS2, Dota 2, Steam) и средах разработки (VS Code, Visual Studio, PowerShell, Windows Terminal) автоисправление автоматически отключается, чтобы не мешать управлению и кодингу.

9. **Автозапуск с Windows в 1 клик**:
   - Настраивается прямо из меню трея через реестр Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

10. **Конфигурация через `config.json`**:
    - Пользовательский словарь, исключения, список программ и сниппеты легко редактируются в файле `config.json`.

## 💻 Управление и горячие клавиши

| Клавиша | Действие |
|---|---|
| **Pause / Break** | Конвертировать последнее слово или выделенный текст (RU $\leftrightarrow$ EN) |
| **Shift + Pause** | Конвертировать всю последнюю набранную строку |
| **Alt + Pause** или **Shift + F3** | Сменить регистр выделенного фрагмента |
| **Двойной Shift** | Быстрое переключение раскладки активного окна |
| **Backspace** | Откат автозамены назад (если нажат сразу после исправления) |
| **Пробел / Enter** | Автоматическое исправление слова при опечатке |

## 📦 Способы запуска

### Вариант 1. Автономный `.exe` (Рекомендуется)
- Запустите **`dist/QWERTY_Switcher.exe`** (или из архива на Рабочем столе).
- Работает на любом ПК с Windows без установленного Python.

### Вариант 2. Фоновый запуск скрипта
- Дважды кликните по **`run.vbs`** — запустится в фоне без черного окна консоли через `pythonw.exe`.
